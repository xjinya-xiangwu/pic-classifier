三步整理一批照片

1. 上方输入文件夹路径 → 扫描(支持 heic / jpg / jpeg / png)
2. 配置模型 API 后 → 开始识别(逐张调用视觉模型判断衣着/姿势/角度)
3. 逐组点击挑选每组的保留照片 → 原地重命名(只改文件名, 可一键撤销)

照片仅压缩后发送给你配置的模型 API; 分组结果与撤销记录保存在 ~/.photocurator/。
